## 它解决什么问题

聊天里费神的往往不是打字，是判断：对方到底想要什么？这句话有没有风险？现在该不该回？怎么回才合适？

Jev 把这一步交给一个专门做判断的模型：它不写字，只从固定选项里选，一次给出真实意图、危险等级（0–9）等多项判断，都带概率。不管你是在手机上用 App，还是在电脑前开着聊天软件，它都贴在聊天旁边，读懂对方刚发的消息，再给出排好序的候选回复。你只需要点一下填进输入框，看一眼，自己按发送。

## 一套内核，四端只换采集

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/jev-chat/.github/main/profile/assets/core-flow-dark.png">
    <img src="https://raw.githubusercontent.com/jev-chat/.github/main/profile/assets/core-flow-light.png" width="880" alt="一套内核流程图。上层「采集」四端各自适配：Android 无障碍读屏，读不到时本机 OCR；Windows 截自己的聊天窗口，本机离线 OCR；iOS 剪贴板；macOS 读窗口里的文字，或截窗口后本机 OCR。四路汇到下层「内核」，四端共用：1 判断（真实意图、危险等级 0–9、该不该马上回，都带概率）→ 2 起草（生成模型顺着判断写候选回复）→ 3 排序（按合适程度重排，标出概率）→ 4 填入（一键进输入框，发送键由你按）。">
  </picture>
</p>

四端共用同一套流程：**判断 → 起草 → 排序 → 填入**。区别只在「怎么拿到屏幕上的对话」：

- **Android**：系统无障碍服务读当前对话；读不到正文时截屏，用 ML Kit 中文离线 OCR 在本机识别。
- **Windows**：截自己的聊天窗口（WGC），用 RapidOCR 在本机离线识别。
- **iOS**：剪贴板。
- **macOS**：读聊天窗口里的文字；读不到文字的应用，截窗口后在本机 OCR。判断默认用本地小模型，也可以接云端。

新增一个平台或聊天 App，只需要换掉「采集」这一层，判断、起草、排序、填入全部复用。

## Android 与 Windows

**Android · 悬浮窗**

- QQ（9.3.50）、X 私信（12.25，中文界面）真机全链路；飞书正文靠本机 OCR；其它 App 可以在悬浮窗菜单里「截屏识别一次」。
- 判断 / 回复 / 视觉三路接口分别可配，内置博查 Jev、OpenRouter、TypeSafe 直连等预设，各自一键测连通。博查 Jev 当前限时免费，key 在 [jev.bocha.cn](https://jev.bocha.cn) 领。
- 本地知识库与联系人档案：常驻笔记每次都带，其余按标签或标题命中当前对话；开了历史，再带上这个人近期的聊天。
- 从旧版升级后，把系统设置里的无障碍开关关掉再打开一次，服务才会重新生效。

**Windows · 窗口旁挂**

- 贴在桌面聊天窗口旁边：截图 + 本机离线 OCR 读出对方的消息，几秒后给出判断摘要和 3 条带胜出概率的候选，推荐那条置顶。
- 跟着当前会话走；群聊会带上发言人名，也可以指定回复给谁。
- 判断走 OpenRouter 或 TypeSafe 直连，起草默认 DeepSeek 官网直连，也能换 OpenAI / Anthropic / Gemini 协议的接口，全程两把 key。
- 只有对方来新消息才调一次模型，没人说话就不调用；标题栏一拨就暂停读取。

## 隐私与边界

这不是一个「什么都不收集」的产品：分析时，聊天文字确实会发给一个模型接口，只是那个地址由你自己配置。具体到四端：

- **读了什么**：只读你自己设备上、你自己有权查看的对话。不改任何 App 的安装包，不走它们的接口或账号，不读数据库。
- **发给谁**：只在分析那一刻，发给你自己配置的模型接口。Android、Windows、iOS 端作者不架设服务器、不经手。macOS 端不配密钥时可以用内置免费通道，这条链路经过作者自建的中转服务器；自配密钥或用本地模型就不经过作者，详见 [macOS 隐私说明](https://github.com/jev-chat/jev-chat-jarvis-mac/blob/master/PRIVACY.md)。
- **存在哪**：密钥只存本机，不进仓库、不进日志。截图只在本机 OCR，不上传。Android、macOS 端的聊天历史默认关闭，开了也只存本机。
- **怎么删**：Android 在设置页「清空知识库与历史」一键删除，卸载会连同密钥、设置一起清空，没有云端备份；macOS 在「会话记录与背景」里管理和清空记录。
- **从不做什么**：四端都只把候选填进输入框，从不自动发送；不碰转账、红包、收款。

完整的 Android 端隐私政策见 [PRIVACY.md](https://github.com/jev-chat/jev-chat-jarvis/blob/main/PRIVACY.md) 与官网 [chatjevs.com/privacy.html](https://chatjevs.com/privacy.html)。
