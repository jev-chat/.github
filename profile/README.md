## Jev 能帮你做什么

- **理解对话**：分析聊天内容，辅助判断对方的意图与沟通风险。
- **准备回复**：结合判断给出候选回复，帮助你决定怎么表达。
- **由你发送**：你选择回复并确认发送，保留最后的决定权。

Android 版通过悬浮窗使用，已验证 QQ、X 私信和飞书等场景；微信 Android 版已全面下架。更多功能、适配范围与限制见 [Android 项目说明](https://github.com/jev-chat/jev-chat-jarvis)。Windows 和 macOS 的功能与安装要求见各自项目主页。

## 数据与隐私

Android 版的截图只在本机进行 OCR；分析时，聊天文字和启用的背景信息会发给你配置的模型服务商。密钥、知识库和可选历史存于本机。详情见 [Android 隐私政策](https://github.com/jev-chat/jev-chat-jarvis/blob/main/cn/PRIVACY.md)。其他平台的数据处理方式请查阅对应仓库说明。
